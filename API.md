# WeTicket
## API документация (Swagger)

### Группы эндпоинтов

| Группа | Префикс | Описание |
|:--|:--|:--|
| Аутентификация | `/auth` | Регистрация, вход, восстановление пароля |
| Пользователи | `/users` | Управление профилем, история |
| Каталог | `/events` | Просмотр и поиск мероприятий |
| Бронирование | `/bookings` | Создание, отмена, оплата бронирований |
| Групповые покупки | `/groups` | Создание групповых сессий, приглашения |
| Администрирование | `/admin` | Управление мероприятиями, статистика |
| Билеты | `/tickets` | Просмотр и валидация билетов |

---

### 1. Аутентификация (`/auth`)

| Метод | Эндпоинт | Описание | Доступ |
|:--|:--|:--|:--|
| POST | `/auth/register` | Регистрация нового пользователя | Открытый |
| POST | `/auth/login` | Вход в систему | Открытый |
| POST | `/auth/logout` | Выход из системы | Авторизованный |
| POST | `/auth/refresh` | Обновление JWT токена | Авторизованный |
| POST | `/auth/forgot-password` | Запрос на восстановление пароля | Открытый |
| POST | `/auth/reset-password` | Сброс пароля по токену | Открытый |


### 2. Пользователи (`/users`)

| Метод | Эндпоинт | Описание | Доступ |
|:--|:--|:--|:--|
| GET | `/users/me` | Получение профиля текущего пользователя | Авторизованный |
| PUT | `/users/me` | Обновление профиля | Авторизованный |
| PUT | `/users/me/password` | Смена пароля | Авторизованный |
| GET | `/users/me/bookings` | История бронирований | Авторизованный |
| GET | `/users/me/tickets` | Список билетов пользователя | Авторизованный |


### 3. Каталог мероприятий (`/events`)

| Метод | Эндпоинт | Описание | Доступ |
|:--|:--|:--|:--|
| GET | `/events` | Список мероприятий с фильтрацией | Открытый |
| GET | `/events/{eventId}` | Детальная информация о мероприятии | Открытый |
| GET | `/events/{eventId}/seats` | Схема зала со статусами мест | Открытый |
| GET | `/events/categories` | Список доступных категорий | Открытый |


### 4. Бронирование (`/bookings`)

| Метод | Эндпоинт | Описание | Доступ |
|:--|:--|:--|:--|
| POST | `/bookings` | Создание нового бронирования | Авторизованный |
| GET | `/bookings/{bookingId}` | Получение информации о бронировании | Авторизованный |
| DELETE | `/bookings/{bookingId}` | Отмена неоплаченного бронирования | Авторизованный |
| POST | `/bookings/{bookingId}/pay` | Оплата бронирования | Авторизованный |
| GET | `/bookings/{bookingId}/payment-status` | Проверка статуса оплаты | Авторизованный |


### 5. Групповые покупки (`/groups`)

| Метод | Эндпоинт | Описание | Доступ |
|:--|:--|:--|:--|
| POST | `/groups` | Создание групповой сессии | Авторизованный |
| GET | `/groups/my` | Список групповых сессий пользователя | Авторизованный |
| GET | `/groups/{sessionId}` | Информация о групповой сессии | Авторизованный |
| GET | `/groups/join/{inviteLink}` | Присоединение к группе по ссылке | Авторизованный |
| POST | `/groups/{sessionId}/cancel` | Отмена групповой сессии | Авторизованный (только организатор) |


### 6. Администрирование (`/admin`)

| Метод | Эндпоинт | Описание | Доступ |
|:--|:--|:--|:--|
| POST | `/admin/events` | Создание мероприятия | Администратор |
| PUT | `/admin/events/{eventId}` | Редактирование мероприятия | Администратор |
| DELETE | `/admin/events/{eventId}` | Удаление мероприятия | Администратор |
| POST | `/admin/events/{eventId}/seats` | Загрузка схемы зала | Администратор |
| POST | `/admin/events/{eventId}/cancel` | Отмена мероприятия с возвратом средств | Администратор |
| GET | `/admin/statistics` | Статистика продаж | Администратор |
| GET | `/admin/users` | Список пользователей | Администратор |
| PUT | `/admin/users/{userId}/block` | Блокировка пользователя | Администратор |


### 7. Билеты (`/tickets`)

| Метод | Эндпоинт | Описание | Доступ |
|:--|:--|:--|:--|
| GET | `/tickets/{ticketId}` | Получение информации о билете | Авторизованный |
| GET | `/tickets/{ticketId}/pdf` | Скачивание PDF билета | Авторизованный |
| POST | `/tickets/validate` | Валидация QR-кода билета (для входа) | Администратор/Организатор |


### Коды ответов HTTP

| Код | Описание |
|:--|:--|
| 200 | Успешный запрос |
| 201 | Создано (для POST запросов) |
| 400 | Неверный запрос (ошибка валидации) |
| 401 | Не авторизован (требуется JWT токен) |
| 403 | Доступ запрещён (недостаточно прав) |
| 404 | Ресурс не найден |
| 409 | Конфликт (например, место уже занято) |
| 422 | Необрабатываемая сущность (ошибка бизнес-логики) |
| 429 | Слишком много запросов |
| 500 | Внутренняя ошибка сервера |
